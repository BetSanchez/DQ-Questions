La aplicación necesita leer data/preguntas.json. Los navegadores bloquean esa lectura cuando abres index.html con doble clic (file://).

Ábrela con un servidor local:

  • En VS Code: clic derecho en index.html → Open with Live Server.
  • En una terminal, dentro de la carpeta del proyecto: python -m http.server 8000 y entra a http://localhost:8000.

Si ya usas un servidor, verifica que el archivo exista y que sea JSON válido.
